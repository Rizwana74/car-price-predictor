# Car Price Predictor Pro - 2026 Edition

ML-powered car price predictor with inflation adjustment, depreciation forecast,
fuel cost estimates, and side-by-side comparisons.

---

## WINDOWS SETUP (Python 3.12.4)

### Option A - One-click setup (easiest)
Double-click `setup.bat` in the project folder.
It installs all packages, retrains the model, and launches the app automatically.

### Option B - Manual setup in terminal
Open a terminal (cmd or PowerShell) inside the `car-price-predictor-new` folder:

    pip install -r requirements.txt
    python retrain_model.py
    streamlit run app.py

Open your browser at: http://localhost:8501

### After first setup - just run the app
Double-click `run.bat`  OR  run in terminal:

    streamlit run app.py

---

## Why you must run retrain_model.py once

The bundled `.pkl` model files were created on a different machine with a
different NumPy version. They MUST be regenerated for your local Python
environment before the app will work. Running `python retrain_model.py`
does this automatically in about 10-15 seconds.
